# zezinho's Train Timer

Shows when the armored train arrives and when it leaves, on maps that have one (Reserve and Lighthouse).

- **In the extraction list**: the train's row normally shows `??:??:??` until you reach it. Now its timer counts down to the train's arrival, then to its departure, and the exit name says which: "(arrives in)", "(leaves in)" or "(has left)".
- **Optional overlay**: a line on screen such as "Armored train arrives in 12:34", off by default.
- English, Portuguese and Russian.
- Client only. Nothing changes on the server.

"Leaves in" counts down to the moment the train starts departing, which is when the exit begins its countdown for the players on board. After that you can no longer board.

## Settings

Press F12 (BepInEx Configuration Manager):

| Section | Setting | Default |
|---|---|---|
| General | Enabled | on |
| General | Language | English |
| Extraction List | Show In Extraction List | on |
| Overlay | Show Overlay | off |
| Overlay | Corner | top right |
| Overlay | Font Size | 18 |
| Overlay | Toggle Key | none |

## Install

Extract the zip into your game folder (the one with `BepInEx`). It adds `BepInEx/plugins/TrainTimer`.

With Fika, every player who wants the times needs the mod.

## Português

Mostra quando o trem blindado chega e quando ele parte, nos mapas que têm trem (Reserve e Lighthouse).

- **Na lista de extrações**: a linha do trem normalmente mostra `??:??:??` até você chegar lá. Agora o tempo conta até o trem chegar, depois até ele partir, e o nome da saída diz qual: "(chega em)", "(parte em)" ou "(já partiu)".
- **Texto na tela opcional**: uma linha como "Trem blindado chega em 12:34", desligada por padrão.
- Inglês e português (opção Language).
- Só no cliente. Nada muda no servidor.

Instale extraindo o zip na pasta do jogo (a que tem `BepInEx`).
